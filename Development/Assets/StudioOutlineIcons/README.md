# Studio Outline

Active icon family for Director's toolbar and matching menus. Fine neutral outlines, blue action accents, green connection accents, and muted red destructive actions. The light variant matches the current Director shell; dark variants are supplied as design assets. Windows high-contrast mode uses the system-color outline renderer. Disabled commands use Windows Forms grayscale rendering.

Geometry: GXDLMSDirector/Development/StudioIcons.cs. Exporter: migration/IconSetThree/IconSetThree.csproj. Both use the same source. Assets include 16 SVGs and 80 transparent PNGs per theme (16, 20, 24, 32, and 48 pixels).
